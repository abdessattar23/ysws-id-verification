🔴 VULNERABILITY STATUS: CONFIRMED

The application IS vulnerable to Airtable formula injection because:

  1. ✗ No email validation before query construction
  2. ✗ Direct string concatenation of user input
  3. ✗ No sanitization of special characters (quotes, parentheses)
  4. ✗ No protection against Airtable formula functions
  5. ✗ No protection against logical operators (OR, AND)

CVSS Score: 9.1 (Critical)

Affected Files:
  • src/pages/api/slack/vouch.ts:16
  • src/pages/api/slack/lookup.ts:14-16
  • src/lib/slack.ts:12-14

Recommended Actions:
  1. Implement strict email validation
  2. Sanitize all user inputs
  3. Use prepared statements or parameterized queries if available
  4. Add input length limits
  5. Implement proper error handling
